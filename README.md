# Nouvel An à Copenhague

Page d'organisation du voyage du Nouvel An 2026-27 : options de transport et de logement, budget estimé, réponses du groupe.

- `docs/index.html` : la page publiée sur GitHub Pages (générée, ne pas modifier à la main).
- `nouvel-an-copenhague.html` : la source, aussi publiée comme artifact claude.ai.
- `build-pages.sh` : régénère `docs/index.html` depuis la source (`sh build-pages.sh`).
- `apps-script/Code.gs` : le script Google Apps Script qui stocke les réponses dans un Google Sheet.
